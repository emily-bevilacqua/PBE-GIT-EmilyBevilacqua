## Git
O Git é um sistema de controle de versão distribuído, criado para registrar e gerenciar o histórico de alterações em arquivos e códigos de um projeto. 


## Github
O GitHub é uma plataforma online de hospedagem de código-fonte e arquivos baseada no sistema de controle de versão Git.

## Push
 O push é uma mensagem enviada diretamente do servidor para o dispositivo do usuário, sem que ele precise abrir um aplicativo ou site para recebê-la.

 ## PULL
  O pull é o comando usado para baixar as atualizações de um repositório remoto e juntá-las automaticamente com o seu projeto local.
